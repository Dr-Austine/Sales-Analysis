# 📊 US Insurance Investment Analytics Dashboard

An interactive dashboard built with **Python, SQL, MySQL, Streamlit, Pandas, and Plotly** to analyze insurance and customer data through dynamic filters, KPIs, and visualizations.

## Project Overview

This project demonstrates an end-to-end analytics workflow:

* Extract data from a MySQL database
* Transform and analyze data using Pandas
* Build interactive dashboards with Streamlit
* Create visualizations using Plotly
* Generate business insights through KPIs and demographic analysis

## Features

✅ Interactive Streamlit dashboard

✅ Dynamic filters for:

* Department
* Country
* City
* Business Unit

✅ KPI Metrics:

* Total Customers
* Average Salary
* Total Annual Salary
* Maximum Salary

✅ Interactive Visualizations:

* Department Analysis
* Salary Distribution
* Workforce Demographics
* Gender Analysis
* Age Distribution

✅ Data Table Explorer

## Installation

Clone the repository:

```bash
git clone <repository-url>
cd us-insurance-investment-analytics-dashboard
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run Main.py
```
