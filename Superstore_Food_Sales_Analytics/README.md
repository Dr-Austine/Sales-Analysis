# 🛒 Superstore Food Sales Analytics Dashboard
![Data Viewer](Attachment/Image%201.png)

An interactive sales analytics dashboard built with **Python, Streamlit, Pandas, Altair, and Matplotlib** to explore sales performance, monitor KPIs, and generate business insights from a retail food dataset.

🔗 **Live Demo:** https://sales-analysis-krzxlkjy3ih692vbnoydwq.streamlit.app/

## Project Overview

This project demonstrates an end-to-end data analytics workflow by:

* Loading and cleaning sales data with Pandas
* Building an interactive dashboard using Streamlit
* Exploring trends through dynamic charts
* Filtering data by date
* Exporting filtered datasets to CSV and Excel

## Features

✅ Interactive Streamlit dashboard

✅ Date range filtering

✅ Key Performance Indicators (KPIs):

* Total Sales
* Quantity Sold
* Average Sale
* Number of Products
* Number of Cities

✅ Executive Sales Summary

✅ Interactive Visualizations:

* Product Quantities
* Sales by Category
* Monthly Sales Trend
* Product vs Total Price
* Unit Price Analysis
* Interactive Scatter Plot
* Feature Frequency Analysis

✅ Exploratory Data Analysis

✅ Data Export

* CSV
* Excel

## Installation

Clone the repository:

```bash
git clone <repository-url>
cd superstore-food-sales-analytics
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
